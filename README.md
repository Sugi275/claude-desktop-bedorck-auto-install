# claude-desktop-bedrock-auto-install

AWS Japan SA が作成した、Claude Desktop 3p (Amazon Bedrock) の導入を自動化するサンプルスクリプト集です。

## 概要

Claude Desktop (Amazon Bedrock) の初期セットアップ（インストール・設定・レジストリ適用）を PowerShell スクリプトで半自動化します。

## 利用手順

詳細な利用手順は以下を参照してください。

- https://zenn.dev/aws_japan/articles/aws-claude-desktop-powershell-auto-install

## 注意事項

本スクリプトはサンプルです。実際にご利用の際は、自社の環境・セキュリティポリシーに合わせて十分に検証したうえでご使用ください。
